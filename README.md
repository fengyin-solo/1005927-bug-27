# 光伏电站运行维护管理平台

面向电站台账、组串阵列、逆变器、汇流箱、跟踪支架、组件清洗、告警处置与发电结算的一体化光伏电站运行维护工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `pv-plant-ops:entries` 这一项，或调用 `resetModule(模块)`。

## 巡视复核派单（patrol × defect）

巡视与消缺的派生规则集中在 `frontend/src/api/patrol-review.ts`：

- **派生只发生一次**：复核派单把每个异常项派生为一张「待派发」消缺单，并在巡视单上写
  `待派台账`；台账落过后异常项数即锁定，再改不小、不删单、不翻倍。
- **同一份事务**：巡视状态、异常项数扣减（`待派异常项数`）、台账落账、消缺单派生在
  `saveAllRows()` 一笔写入；已派条数大于当前异常项数等扣减不平的情况整笔回滚，一项都不动。
- **中断可续**：台账按异常项次记录，重试只补缺的那一项；消缺单已存在但台账缺项时按
  「巡视单号+项次」接回，绝不重复派生。接不上的项把原因写进 `派单失败原因` 与台账备注，
  巡视单保持待复核并标异常，不会静默停在半路。
- **断流不顶旧数据**：派生消缺单取不到对应巡视单时，业务字段原样保留、标记 `关联失败`，
  巡视单补回后用「重试关联」重新挂账。
- **拒收规则**：派过单的巡视单不再收复核，并提示已派到哪些缺陷编号；跳级动作（待巡视/
  巡视中直接复核）直接拦下。
- **权限**：异常项数登记、提交复核、复核派单只认巡视单上的本路线巡视人；岗种带
  消缺/检修字样（既巡又修）的人员一律不收。页面顶部可切换当前操作人验证。
- **对账**：巡视页「台账对账」校验派单条数 = 待派台账 = 两处异常项数，并列出断流单与
  待补录的历史单。消缺单状态流转会同步回写台账状态。
- **异常项数辨认**：宽松解析（`3项`→3、非数字→0、超过检查项数钳到上限），兼容旧巡视
  记录里的脏值。
- **历史补录**：应用启动时对已完成或巡视日期早于今天、但没落台账的旧巡视单按巡视日期
  从早到晚幂等补录（有异常项派单、零异常补盖完成），标记 `补录: true` 与操作人「历史补录」。

领域规则的可执行验证在 `frontend/scripts/verify-patrol.mjs`，运行：

```bash
cd frontend
npm run verify:patrol
```
