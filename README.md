# 光伏电站运行维护管理平台

面向电站台账、组串阵列、逆变器、汇流箱、跟踪支架、组件清洗、告警处置与发电结算的一体化光伏电站运行维护工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

行为验证（无需浏览器）：

```bash
cd frontend
npm run test:domain   # 巡视复核→消缺派生的领域规则（81 项断言）
npm run test:e2e      # 走真实 localStorage 持久化路径的端到端冒烟（32 项断言）
```

## 巡视复核 → 消缺派生

巡视与消缺之间是强一致的一次性派生关系，规则集中在
`frontend/src/data/patrol-domain.ts`（页面只渲染，不做业务判断）：

- **同一份数据、整笔提交**：巡视状态、异常项数、派生消缺单、消缺侧「待派台账」同处一份整库快照
  （`src/data/types.ts` 的 `Database`），每次提交整体写入 localStorage。派生前置校验不通过一笔不写，
  落库失败也不换内存快照，等同整笔回滚。
- **派生只发生一次**：每个异常项按序号（1…异常项数）只派生一张消缺单，台账记实链；
  重复复核、异常项数被改小都不会让已派单据蒸发或翻倍。
- **断点续派**：复核提交中途中断（如写入失败）后可重试，只补还没派的那一项；
  台账与消缺表接不上时把原因写到巡视单「中断原因」并挂起，不会沉默停在半路。
- **状态逐级**：待巡视→巡视中→待复核→已完成，跳级直接拦下，并指出已派到哪一张消缺单；
  已派过单的巡视单不再收复核。
- **异常项数权限**：只有本路线巡视人（巡视人员字段）能改；巡视人若在册维修/检修/消缺岗位
  （既巡又修）一律不收；台账建立后异常项数锁死。顶栏可切换当前值班身份用于演示。
- **待派台账核对**：巡视页「核对待派台账」逐单校验两处异常项数一致、派单条数与台账一致、
  每张消缺单真实存在且回链一致；消缺单「派发消缺」后回写台账行状态（部分/全部已派发）。
- **异常项识别**：阿拉伯数字、纯数字串、中文简写数字（三、十二、二十…）都认；
  认不出的历史脏数据按 0 展示并标「异常项数待核实」，由本路线巡视人确认，绝不瞎派。
- **历史补录**：老版本 localStorage（`Record<模块, 行[]>`）首次读取自动迁移；
  历史已完成巡视单按巡视日期补录台账与消缺单（发现方式标「历史巡视补录」），迁移幂等。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `pv-plant-ops:entries` 这一项，或调用 `resetModule(模块)`。
